# AETHER — Premium Fashion Store

AETHER is a modern, premium-style fashion e-commerce website designed with a dark aesthetic, glassmorphism UI, responsive layouts, and interactive shopping features.

The project is designed as a frontend fashion-store concept and can be used as a starting point for a real clothing brand or e-commerce business.

## ✨ Features

- 🛍️ Modern fashion e-commerce interface
- 🌑 Dark premium UI
- 🪟 Glassmorphism product cards and components
- 📱 Fully responsive design
- 👕 Fashion product categories
- 🛒 Interactive shopping cart
- ➕ Add products to cart
- ➖ Remove products from cart
- 💰 INR / USD currency selection
- 📦 PAN India delivery section
- 📧 Buy Now / Email Order functionality
- 📱 Mobile-friendly navigation
- 🔔 Interactive notifications
- 🎨 Modern typography and animations
- 🖼️ Fashion-focused product presentation

## 🗂️ Product Categories

The website currently includes categories such as:

- Premium T-Shirts
- Hoodies & Sweats
- Outerwear
- Bottoms

## 🛠️ Technologies Used

- HTML5
- CSS3

- Google Fonts
